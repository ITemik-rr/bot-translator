# Бот-переводчик

## Что умеет этот бот?
1. _Переводить с 4 языков(Английский, китайский, немецкий, арабский)_
2. _Сохранять запрос с переводом_
3. _Помогает выбрать язык для перевода_

### Команды и функции:
1. _/start - бот приветствует пользователя и просит ввести /help_
2. _/help - бот рассказывает про команды_
3. _/language - бот предоставляет выбор языка_
4. _/translate <текст для перевода> - команда для перевода текста пользователя_
5. _lambda команда - для сохранения данных в базу данных_

 start_command - для первой команды
 
 send_help - для второй команды
 
 choose_language - для третьей команды (кнопки для выбора языка)
 
 translate_text - для перевода текста пользователя
 
 save_message - для пятой команды.

#### Файлы проекта
1. _logic.py - таблица (user_id, user_text, translation, date)_
2. _main.py - бот_
3. _config.py - токен_
